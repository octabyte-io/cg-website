## What every guide assumes

- **A Server or a Cloud account.** Cloudgate deploys onto a [Server](/docs/guide/servers) it reaches
  over SSH, or into your [AWS or Google Cloud account](/docs/guide/cloud-accounts). The
  [quickstart](/docs/quickstart) gets you one, including buying a server on the Hosted instance.
- **A Project with an Environment.** The examples use a Project `storefront` with an Environment
  `production` on the Server `fra-1`. See [Projects and Environments](/docs/guide/projects-and-environments).
- **Your code in git or in a folder.** Connect GitHub, GitLab, Bitbucket or Gitea, give any git URL,
  or upload a folder with the CLI.
- **The owner or admin role to create Services.** Members can change and deploy the Services they
  are granted. See [members and roles](/docs/guide/members-and-roles).

## The settings every app needs

| Setting | Where | Why it matters |
|---|---|---|
| **Builder** | **Build** card on the Overview | Nixpacks by default; Dockerfile, Railpack, Heroku or Paketo buildpacks when you prefer them. |
| **Container port** | **Advanced** > **Routing** | The port your app listens on. Defaults to 3000; Traefik sends traffic there. |
| **Run command** | **Advanced** > **Runtime** | The command that starts the app, when the builder's guess is not the one you want. |
| **Variables** | **Variables** tab | One `KEY=value` per line, plus wired variables such as `DATABASE_URL` linked to a database's `url`. |
| **Domains** | **Domains** tab | A free `sslip.io` address at once, or your own host with a Let's Encrypt certificate. |

Cloudgate does not set a `PORT` variable for an app on a Server. If your framework reads `PORT`, set
it on the **Variables** tab to the same number as the **Container port**.
